# 🌸 Multiclass Logistic Regression – Machine Learning Project

This repository contains a complete implementation of **Multiclass Logistic Regression** using Python, Google Colab, and Scikit-Learn.  
The model is designed to classify data into **three or more classes** using the Softmax function.

---

## 📌 Project Overview
Multiclass Logistic Regression is an extension of binary logistic regression.  
Instead of predicting **Yes/No**, it predicts **multiple categories** such as:

- Type of flower  
- Type of disease  
- Type of customer  
- Any multi-category classification problem  

This project demonstrates:
- Data loading  
- Exploratory Data Analysis  
- Preprocessing  
- Model training  
- Evaluation  
- Visualization  

---

## 🚀 Features
- Implemented using **Softmax Logistic Regression**
- Uses **Cross-Entropy Loss**
- Supports multi-class datasets
- Easy to run in Google Colab
- Clean and simple code structure
- Graphs included for understanding
